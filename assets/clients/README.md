# Client logos

These marks appear next to each client on the settings screen, in the project README and in the banner. `dark/` holds the versions for dark backgrounds. The plugin loads `assets/clients/<client-id>.svg`, so to replace a mark, swap the file.

Every logo is a trademark of its owner. It is shown only to say the plugin works with that client. No affiliation, sponsorship or endorsement is implied. Each mark is unmodified and appears smaller than the plugin's own branding.
